# เครื่องมือดูแลคลังข้อสอบ

ที่เก็บ "ต้นฉบับ" ของงานซ่อมคลังข้อสอบ ตัวโจทย์จริงอยู่ใน Firestore
โฟลเดอร์นี้เก็บ **ที่มาของทุกข้อที่แก้** ไว้ให้ย้อนตรวจและทำซ้ำได้

## dedup — แทนข้อที่ซ้ำกัน

`dedup/sets/*.py` คือต้นฉบับของโจทย์ใหม่ 101 ข้อที่เขียนแทนข้อซ้ำ
ทุกข้อคำนวณคำตอบด้วย SymPy สดจากโจทย์ ไม่ได้พิมพ์เลขคำตอบลงไปเอง
`dedup/kit.py` เป็นด่านตรวจกลาง จะไม่ยอมให้ผ่านถ้า

- `options[correctIndex]` ไม่ตรงกับค่าที่ SymPy แก้ได้
- ตัวเลือกซ้ำกัน หรือตัวลวงชี้ไปที่คำตอบถูก
- เฉลยขึ้นต้นไม่ตรงกับตำแหน่งคำตอบ หรือสั้นกว่า 700 ตัวอักษร

### นิยาม "ซ้ำจริง"
โจทย์เหมือนกัน **และ** ตัวเลือกเป็นชุดเดียวกันทั้งชุด
ข้อที่โจทย์ขึ้นต้นเหมือนกันแต่ตัวเลือกคนละชุด **ไม่นับว่าซ้ำ** เพราะเป็นคนละข้อกันจริง
(เช่นชุดจำนวนจริง ม.2 ถาม "ข้อใดเป็นจำนวนอตรรกยะ" 8 ครั้ง แต่ตัวเลือกต่างกันหมด)

### วิธีทำ
```
node scripts/exam-maintenance/dedup/tools/recount.js          # หาว่าเหลือข้อซ้ำจริงกี่ข้อ
node scripts/exam-maintenance/dedup/tools/spec.js <examId>    # ดูตำแหน่ง + ci ที่ต้องคง
python3 scripts/exam-maintenance/dedup/sets/<ชื่อ>.py          # สร้าง out-*.json
node scripts/apply-dedup.js <out-*.json>                      # dry-run
node scripts/apply-dedup.js <out-*.json> --apply              # เขียนจริง
node scripts/bust-caches.js exams
```

**กติกาที่ห้ามพลาด:** ข้อใหม่ต้องคง `correctIndex` ตำแหน่งเดิม
ไม่งั้นการกระจายคำตอบ ก/ข/ค/ง ของทั้งชุดจะเสีย

## tagging — เติม tag 4 มิติ

ระบบวิเคราะห์จุดอ่อนต้องใช้ tag ครบสี่มิติรายข้อ คือ **สาระ + หัวข้อย่อย + ทักษะ + ระดับ + ชั้น**
`tagging/sets/*.py` คือคำตัดสินรายข้อของแต่ละชุด (ตอนนี้ครบ ม.1 ทั้ง 6 ชุด)

**ทำอัตโนมัติไม่ได้** — `tagging/tools/classify.py` คือตัวจำแนกที่ลองสร้างดู
วัดกับชุดที่มี tag อยู่แล้วได้ความแม่นทักษะ 54% ระดับ 43% ซึ่งต่ำเกินจะใช้จริง
เก็บไว้เป็นหลักฐานว่าเคยลองแล้วไม่ผ่าน ต้องอ่านโจทย์ทุกข้อแล้วตัดสินเอง

**ห้ามบังคับสัดส่วน 25/40/25/10** กับชุดที่มีอยู่แล้ว นั่นเป็นพิมพ์เขียวสำหรับออกชุดใหม่
ชุดเก่าต้องติดป้ายตามความจริง

```
node scripts/exam-maintenance/tagging/tools/export.js   # ดึงคลังออกมา
node scripts/apply-exam-tags.js <ชื่อ>                   # dry-run
node scripts/apply-exam-tags.js <ชื่อ> --apply
```

## audit — สคริปต์ตรวจคลัง

- `gap-report.js` — ชุดทั้งหมดแยกตามหมวด พร้อมธงว่าชุดไหนไม่มีปก/tag ไม่ครบ
- `tag-coverage.js` — ชุดไหนพร้อมป้อนระบบวิเคราะห์จุดอ่อนแล้ว ชุดไหนยัง
- `offtopic-scan.js` — หาข้อที่ tag ไม่เกาะหัวข้อหลักของชุด (ใช้จับ "ของปน")

## ที่ไม่ได้เก็บไว้

ไฟล์สำรองของโจทย์เดิมก่อนแทน อยู่ที่ `scripts/tmp/dedup/backup/<examId>.json` บนเครื่อง
ไม่ได้ commit เพราะรวมกันเกือบ 10 MB และเป็นข้อที่ตั้งใจเอาออกอยู่แล้ว
