# เกลี่ยตำแหน่งคำตอบ ก/ข/ค/ง

## ปัญหา

บางชุดตำแหน่งคำตอบกระจุกอยู่ตัวเดียว เด็กฝนตัวเดิมรวดทั้งชุดก็ได้คะแนนเกินจริง
คะแนนจึงไม่สะท้อนความสามารถ และระบบวิเคราะห์จุดอ่อนก็อ่านผิดตาม

> ⚠️ ถ้าเจอชุดที่ตัวเลือกไหน **ไม่เคยเป็นคำตอบเลยสักข้อ** อย่าเพิ่งมาเกลี่ย
> นั่นไม่ใช่การออกแบบเอียง แต่เป็นสัญญาณว่าเฉลยชี้ผิดตัว — ดู `../answerfix/README.md`

## ที่เครื่องมือนี้ทำ

สลับตำแหน่งตัวเลือกแค่ **สองตำแหน่ง** ต่อข้อ (คำตอบ ↔ ตัวเลือกที่อยู่ตำแหน่งเป้าหมาย)
แล้วแก้ให้ครบทุกที่ที่อ้างตำแหน่ง — `correctIndex`, `answerIndex`, หัวเฉลย, `distractorErrors`

**แตะเฉพาะข้อที่ปลอดภัยจริง** ข้อไหนเข้าเงื่อนไขไม่ครบ ปล่อยไว้เฉยๆ

1. เฉลยต้อง **ไม่อ้างถึงตัวเลือกด้วยตำแหน่ง** นอกจากหัวเฉลย (ไม่มี "ตัวเลือก 1" / "ข้อ ก.")
   เพราะสลับแล้วข้อความพวกนั้นจะชี้ผิดตัว ซึ่ง **แย่กว่าปล่อยให้เอียง**
2. ตัวเลือกต้อง **ไม่ได้เรียงลำดับตัวเลขอยู่แล้ว** — ชุดที่เรียงไว้อ่านง่ายกว่า ไม่ควรไปรื้อ
3. ตัวเลือกต้องไม่อ้างถึงกันเอง ("ถูกทุกข้อ" / "ข้อ ก. และ ข.")
4. หัวเฉลยต้องอ่านออกและตรงกับ `correctIndex` อยู่แล้ว

ทุกข้อที่สลับผ่านด่านตรวจห้าชั้นก่อนเขียน — ชุดตัวเลือกต้องเป็นชุดเดิม, ข้อความคำตอบต้องไม่เปลี่ยน,
หัวเฉลยใหม่ต้องอ่านแล้วได้ตำแหน่งใหม่, ตัวเลือกต้องไม่ซ้ำ, เนื้อเฉลยต้องไม่เปลี่ยนนอกจากหัว
