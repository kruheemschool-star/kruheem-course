# ตัวเลือกที่ "หน้าตา" ใบ้คำตอบ

## ปัญหา

ถ้าตัวเลือกในข้อเดียวกันเขียนคนละแบบ เช่น

```
ก. $23\frac{1}{3}$ เส้น     ← ฟอนต์คณิต
ข. 20 เส้น                  ← ฟอนต์ปกติ  ← เฉลยข้อนี้
ค. $\frac{1}{20}$ เส้น      ← ฟอนต์คณิต
ง. $21\frac{2}{3}$ เส้น     ← ฟอนต์คณิต
```

เด็กมองปราดเดียวก็เห็นว่า ข. หน้าตาไม่เหมือนพวก แล้วเดาถูกโดยไม่ต้องคิดเลข
เกิดขึ้นเองตามธรรมชาติเวลาคำตอบออกมาเป็นจำนวนเต็มพอดี ส่วนตัวลวงเป็นเศษส่วน
คนเขียนเลยพิมพ์คำตอบเป็นเลขเปล่า ไม่ได้ตั้งใจใบ้ แต่ผลคือใบ้

## สแกนทั้งคลัง 2026-08-27

18,647 ข้อ → เจอ **182 ข้อ / 336 ตัวเลือก** ใน 17 ชุด ที่ตัวเลขปนสองโหมด
ในนั้น **52 ข้อที่คำตอบถูกเป็นตัวเดียวที่โดดออกมา** = ใบ้คำตอบตรงๆ
แก้แล้วทั้งหมด · บันทึกก่อน-หลังทุกตัวอยู่ใน `changelog-20260827.json`

## ขอบเขตที่แก้ (จงใจแคบ)

แก้เฉพาะตัวเลือกที่ **ขึ้นต้นด้วยตัวเลข** เช่น `20 เส้น` `1` `7.5` `1,750 มิลลิลิตร`
`125.40, 125.49, 126.01, 126.10` — พวกนี้คือ "คำตอบตัวเลข" ที่ควรอยู่ในโหมดคณิตเหมือนเพื่อน

**ไม่แตะ**
- ประโยคไทยที่บังเอิญมีเลขแทรกกลาง เช่น `มีค่าน้อยกว่าร้อยละ 90 ของพื้นที่ทั้งหมด`
  เลขกลางประโยคเป็นการพิมพ์ปกติ ใส่ `$` แล้วฟอนต์จะแปลกกลางประโยค และไม่ได้ใบ้อะไรอยู่แล้ว
- ตัวเลือกที่มี LaTeX ลอยนอกโหมดคณิต เช่น `x^5y^6` ต้องครอบทั้งก้อน ไม่ใช่ครอบทีละเลข — ให้คนตัดสิน
- ตัวเลือกที่ต่างกันโดยเนื้อหาจริง เช่น `ไม่มีคำตอบ` `มากมายนับไม่ถ้วน` เป็นคำตอบคนละชนิด ไม่ใช่ความพลาดของการจัดรูปแบบ

## กติกาสำหรับของใหม่

**ตัวเลือกทั้งสี่ตัวในข้อเดียวกันต้องจัดรูปแบบเดียวกัน**
ตัวไหนเป็นตัวเลข ให้ครอบ `$...$` ทุกตัว อย่าปล่อยเลขเปล่าปนกับ LaTeX
(ตัวสร้างข้อสอบใน `dedup/syskit.py` บังคับไว้แล้วที่ฟังก์ชัน `N()`)

## เครื่องมือ

```bash
node scripts/exam-maintenance/optfmt/scan.js            # สแกน เขียน report.json
node scripts/exam-maintenance/optfmt/apply.js           # dry-run
node scripts/exam-maintenance/optfmt/apply.js --apply   # เขียนจริง
node scripts/bust-caches.js exams                       # ต้องรันทุกครั้งหลังเขียนจริง
```

`apply.js` สำรองชุดเดิมไว้ที่ `optfmt/backup/<examId>-<stamp>.json` (ตั้ง stamp ด้วย `OPTFMT_STAMP`)
ตั้งใจให้ชื่อไม่ซ้ำ เพราะ `apply-dedup.js` เคยเขียนทับ backup ของตัวเองจนของเดิมหายมาแล้ว
